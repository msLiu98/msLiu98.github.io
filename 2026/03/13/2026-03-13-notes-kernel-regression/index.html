前言

核回归是统计学中重要的非参数回归方法，本文汇总核回归的理论基础、常见核函数以及 Python 实现方法。

一、核回归概述

1.1 定义

核回归（Kernel Regression）是统计学中用于估计随机变量条件期望的非参数方法，目的是找到随机变量 $X$ 和 $Y$ 之间的非线性关系：

$$E(Y|X) = m(X)$$

其中 $m(·)$ 是一个未知函数，通过核函数进行局部加权估计。

1.2 与线性回归的区别

特性 线性回归 核回归
模型形式 预设线性关系 不预设函数形式
参数数量 固定参数 无显式参数
灵活性 低 高
过拟合风险 较低 需调节带宽

二、Nadaraya-Watson 估计量

2.1 基本表达式

1964年，Nadaraya 和 Watson 独立提出了核回归的经典估计方法：

$$\hat{m_h}(x) = \frac{\sum_{i=1}^{n} K_h(x-x_i) y_i}{\sum_{j=1}^{n} K_h(x-x_j)}$$

直观理解：

  • 分子：加权求和，靠近估计点 $x$ 的样本 $y_i$ 获得更大权重
  • 分母：权重归一化，确保总和为1
  • $K_h$：带宽为 $h$ 的核函数

2.2 数学推导

从条件期望定义出发：

$$E(Y|X=x) = \int y \frac{f(x,y)}{f(x)} dy$$

使用核密度估计对联合分布进行估计：

$$\hat{f}(x) = \frac{1}{n}\sum_{i=1}^{n}K_h(x-X_i)$$

$$\hat{f}(x,y) = \frac{1}{n}\sum_{i=1}^{n}K_h(x-x_i)K_h(y-y_i)$$

代入条件期望公式，最终可得：

$$\hat{m_h}(x) = \sum_{i=1}^{n}W_{hi}(x)y_i$$

其中权重：

$$W_{hi}(x) = \frac{K_h(x-x_i)}{\sum_{j=1}^{n}K_h(x-x_j)}$$

三、常见核函数

3.1 高斯核（Gaussian Kernel）

最常用的核函数：

$$K_h(u) = \frac{1}{\sqrt{2\pi}h} \exp\left(-\frac{u^2}{2h^2}\right)$$

特点：

  • 平滑、无限可微
  • 支撑集为整个实数域
  • 计算相对复杂

四、带宽选择

4.1 带宽的影响

带宽 $h$ 是核回归的关键超参数：

  • $h$ 太小：过拟合，估计方差大，曲线波动剧烈
  • $h$ 太大：欠拟合，估计偏差大，曲线过于平滑
  • **最优 $h$**：偏差-方差权衡的最优点

六、核回归的应用场景

6.1 金融时间序列

  • 收益率分布估计：非参数估计收益率密度
  • 波动率曲面拟合：期权隐含波动率的平滑插值
  • 趋势提取：去除噪声，提取价格趋势

6.2 图像处理

  • 图像去噪：局部加权平均去噪
  • 图像插值：超分辨率重建

6.3 经济学

  • 生产函数估计：非参数估计投入产出关系
  • 需求函数估计：消费者行为建模

七、核函数性质总结

7.1 基本性质

有效的核函数需满足：

  1. 非负性：$K(u) \geq 0$
  2. 归一化：$\int K(u) du = 1$
  3. 对称性：$K(u) = K(-u)$
  4. 有限支撑：$K(u) = 0$ 当 $|u| > c$

7.2 收敛性

在满足一定条件下，Nadaraya-Watson 估计量具有一致性：

$$\hat{m_h}(x) \xrightarrow{p} m(x), \quad \text{当 } n\to\infty, h\to0$$

总结

核回归是强大的非参数工具，无需预设函数形式即可估计变量间的非线性关系。关键在于合理选择核函数和带宽参数，通过交叉验证等方法可以优化模型性能。
