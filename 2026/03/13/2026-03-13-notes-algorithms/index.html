前言

算法是编程的核心基础，本文汇总动态规划和双指针两大经典技巧的核心知识点与实战应用。

一、动态规划（Dynamic Programming）

1.1 核心思想

动态规划通过将原问题分解为相对简单的子问题来求解复杂问题，适用于具有以下性质的问题：

  1. 最优子结构：问题的最优解包含子问题的最优解
  2. 无后效性：子问题的解一旦确定，不再受后续决策影响
  3. 重叠子问题：子问题被重复计算，可用记忆化优化

1.2 解题步骤

  1. 定义状态：确定 DP 数组的含义
  2. 状态转移方程：找出状态之间的关系
  3. 初始化：设置边界条件
  4. 遍历顺序：确定计算顺序
  5. 返回结果：从 DP 数组中提取答案

1.3 经典问题：0/1 背包

问题描述：
有 n 件物品，每件物品重量为 $w_i$，价值为 $v_i$。背包容量为 $C$，求能装入背包的最大价值。

状态定义：
$dp[i][j]$ 表示前 $i$ 件物品，容量为 $j$ 时的最大价值

状态转移：
$$
dp[i][j] = \max(dp[i-1][j], \quad dp[i-1][j-w_i] + v_i)
$$

1.4 经典问题：最长公共子序列（LCS）

问题描述：给定两个序列，找出它们最长的公共子序列长度。

状态转移方程：
$$
dp[i][j] = \begin{cases}
dp[i-1][j-1] + 1 & \text{if } X[i] = Y[j] \
\max(dp[i-1][j], dp[i][j-1]) & \text{otherwise}
\end{cases}
$$

1.5 经典问题：打家劫舍

问题描述：
一排房屋，相邻房屋有安保系统，不能同时偷相邻两家，求能偷到的最大金额。

状态转移：
$$
dp[i] = \max(dp[i-1], \quad dp[i-2] + nums[i])
$$

1.6 动态规划分类总结

类型 代表问题 特点
线性 DP 爬楼梯、打家劫舍 一维状态转移
区间 DP 最长回文子串 状态表示区间
背包 DP 0/1背包、完全背包 资源限制类问题
树形 DP 打家劫舍 III 在树上进行 DP
状态压缩 DP 旅行商问题 状态用二进制表示
