Python 代码优化技巧与常见陷阱（错题集）

前言

本文整理了 Python 开发中常见的性能优化技巧、易错点以及”错题集”，帮助你在日常开发中写出更高效、更 Pythonic 的代码。

一、字符串操作优化

1. 字符串连接：join vs +

性能对比：当连接大量字符串时，join 比 + 快数十倍。

2. 字符串格式化对比

二、列表操作优化

1. 列表推导式 vs for 循环

2. 生成器表达式处理大数据

3. 使用 set/dict 进行 O(1) 查找

4. 列表去重并保持顺序

三、循环优化技巧

1. 使用 enumerate 获取索引

2. 使用 zip 并行迭代

3. 使用 map/filter 还是列表推导？

四、函数优化

1. 使用 lru_cache 缓存结果

2. 使用 partial 固定参数

3. 使用 slots 减少内存占用

五、常见陷阱与错题集

陷阱 1：可变默认参数

原因：默认参数在函数定义时只创建一次，而不是每次调用时。

陷阱 2：在循环中修改列表

陷阱 3：闭包延迟绑定

陷阱 4：is vs ==

陷阱 5：类属性与实例属性混淆

陷阱 6：try/except 过于宽泛

陷阱 7：忘记关闭文件

六、import 优化

1. 避免循环导入

2. 使用 all 控制导出

七、性能分析工具

1. 使用 timeit 测量代码

2. 使用 cProfile 分析性能瓶颈

八、实用优化清单

场景 不推荐 推荐
字符串连接 + join()
字符串格式化 % 或 format() f-string
列表过滤 filter() + lambda 列表推导式
查找元素 list.index() set 或 dict
频繁函数调用 直接调用 @lru_cache
大数据遍历 列表 生成器
属性访问 obj.attr local_var = obj.attr
文件操作 open/close with 语句

总结

Python 代码优化是一门平衡的艺术：

  1. 先写对，再写好：功能正确是第一位
  2. 避免过早优化：除非性能确实是瓶颈
  3. 使用工具分析：不要凭感觉，用 profiler 找出真正的瓶颈
  4. 保持可读性：过度优化可能降低代码可维护性

记住：”可读性 counts” 是 Python 的核心价值观！
